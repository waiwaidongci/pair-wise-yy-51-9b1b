# 铁路危险货物运输路径审批与风险复核平台

源提示词编号：8。包含危险货物运输单编组、候选路径生成、MapLibre 路网风险叠加、Turf 里程测算、安全/运营/应急逐区段会签、替代方案与审计基线。

## 技术栈

Angular、Angular Material、NgRx、Angular Router、HttpClient、RxJS、MapLibre GL、Turf.js、TypeScript。

## 统一路线版本模型

路径编组、风险地图、逐区段会签共用同一份路线版本（`RouteVersion`），路径区段、风险等级/总风险分、三方会签意见全部锚定在版本上：

- **生成替代方案**：复制当前版本的全部区段，高风险区段生成绕行区段，风险等级与总风险分统一重算；原有安全/运营/应急意见只继承给未变化区段，绕行承接区段与风险等级变化的区段意见转为「待重新确认」。
- **风险复核**：在风险地图调整区段风险等级会同步作用于当前版本，并把该区段仍有效（非已退回）的会签意见转为「待重新确认」。
- **锁定门槛**：安全、运营、应急三方意见齐备且全部接受，且高风险绕行区段全部处理完，版本才能锁定。
- **锁定只读**：锁定后路径、风险与会签结果不可修改；再调整须「另开修订版本」，旧版本仍保留可查看，版本链完整。
- **持久化**：版本、当前选中版本、待确认意见、锁定状态写入 `localStorage`；切换页面或刷新/重新读取后不回退演示数据。演示数据仅在首次进入时作为 v1 基线。

核心规则在 `src/app/store/route.domain.ts`（纯函数，可单测），可用 `node scripts/verify-domain.cjs` 验证继承、重算与锁定规则。
